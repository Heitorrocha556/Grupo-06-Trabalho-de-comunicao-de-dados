# Trabalho 01

Projeto desenvolvido no **Cisco Packet Tracer** e armazenado no arquivo [`Trabalho 01.pkt`](./Trabalho%2001.pkt).

## Sobre o arquivo

O formato `.pkt` é um arquivo binário utilizado pelo Cisco Packet Tracer. Por isso, seu conteúdo não deve ser convertido diretamente para Markdown: ele precisa ser aberto no Packet Tracer para visualizar a topologia, os dispositivos e as configurações de rede.

## Como abrir

1. Instale o [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer).
2. Baixe o arquivo [`Trabalho 01.pkt`](./Trabalho%2001.pkt).
3. Abra o arquivo pelo Cisco Packet Tracer ou use **File > Open**.
